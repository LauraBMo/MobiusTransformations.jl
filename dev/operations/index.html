Operations

Transformations compose, invert, and compare as projective maps — equal up to a scalar multiple of the coefficients.

g = Möbius(0, 1, 1, 0)            # z -> 1/z
isone(g * inv(g))                  # true
Möbius(1, 2, 3, 4) == Möbius(2, 4, 6, 8)   # scalar multiples are equal
Base.inv — Function
inv(m::MöbiusTransformation)

Return the inverse Möbius transformation. For m = Möbius(a, b, c, d), we have Matrix(inv(m)) = [d, -b; -c, a].

Linear algebra

A transformation carries a 2×2 coefficient matrix [a b; c d], with the usual determinant and projective normalization.

m = Möbius(1, 2, 3, 4)
Matrix(m)          # [1 2; 3 4]
det(m)             # 1*4 - 2*3
normalize(m)       # det == 1
Base.Matrix — Type
Matrix(m::MöbiusTransformation)

Return the 2×2 coefficient matrix [a b; c d] of m.

source
LinearAlgebra.det — Function
det(m::MöbiusTransformation)

Return the determinant a*d - b*c of the coefficient matrix of m=Möbius(a, b, c, d).

source
LinearAlgebra.normalize — Function
normalize(m::MöbiusTransformation)

Returns a Möbius transformation m2 such that m2 == m and det(m2) = 1. Requires sqrt(det(m)) to be defined in the coefficient field.
