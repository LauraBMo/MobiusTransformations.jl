Evaluation

A MöbiusTransformation is callable, mapping a point z to

\[m(z) = \frac{a z + b}{c z + d}.\]

Evaluation at Inf is handled, and a pole (vanishing denominator) returns the value set by set_infinity. Maps broadcast elementwise over collections.

m = Möbius(1, 2, 3, 4)
m(0), m(1), m(Inf)
m.([0, 1, Inf])
MobiusTransformations.MöbiusTransformation — Method
(m::MöbiusTransformation)(z)

Apply the Möbius transformation to a point z, giving m(z) = (a*z + b) / (c*z + d).

The point at infinity — by default Inf, or the value set by set_infinity — is accepted and evaluates to the limit a / c. A pole (vanishing denominator) evaluates to INF.

broadcastable(m::MöbiusTransformation)
